# Skill Munch

A responsive Skill Munch prototype connecting people with local talent and event opportunities.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — browser-side interactions and demo data

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Deploy on GitHub Pages or Vercel
Upload all three files to the same project/root folder. Keep the filenames unchanged.
Note: this demo stores data in the browser's localStorage; it does not use a shared production database.
